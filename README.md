# 数跃 ShuYue

**数学学习智能体（AI Agent）**——高考 → 中外合办大学数学衔接，专为北邮-QMUL 式中外合办项目的大一新生设计。

> **核心问题**：高考数学（中文计算）→ 全英文大学数学（证明导向）的**双重断层**——数学范式 + 语言适应。
>
> **V4 起，数跃是一个真正的智能体**：它有 15 个工具、10 项教学技能、五层记忆、遗忘曲线模型和一个计算沙盒——会自主决定调工具、会验证自己的计算、会在你快忘记时主动提醒你。

## 核心能力

### 智能体（V4 新增）

| 能力 | 说明 |
|------|------|
| **Agent 助手** | 自主工具调用智能体：15 个工具（解题/出题/笔记/单词本/图谱/画板/诊断…）+ 10 项教学技能（苏格拉底/高考桥接/错因分析/证明教练…）。多工作台隔离对话、后台续跑、`+` 菜单与 `/` 命令、`@` 引用你的文档、五层记忆（会话/压缩/状态/语义/长期策展——AI 记得你的薄弱点和偏好） |
| **贴图即问** | 聊天框 Ctrl+V 粘贴图片即可：**手写作业批改**（逐题对错+错步定位+五类归因，等价答案不误判）、**拍照解题**（VL 提取 + Harness 验证双保险）、**教材讲解**（高考→大学四层结构）。批改每日 20 次配额，解题讲解不限 |
| **记忆引擎（FSRS-5）** | 每次答题/批改实时更新记忆状态（难度 D / 稳定性 S / 回忆概率 R）；知识图谱节点按记忆保持度红黄绿着色；到期复习提醒（邮件可关，一键退订）；Dashboard 掌握度数字随答题动态变化 |
| **主动陪伴** | 每日 08:00 到期扫描 + 每周五自动**学习周报**（答题聚合 + AI 点评）与**计划自适应进化**（按本周表现插入补强/复习任务，演进不推倒） |
| **计算沙盒** | 隔离 Python 环境（sympy/numpy 白名单 + 三层安全隔离，攻击测试 38/38 零逃逸）——AI 涉及精确计算时**先验证再回答**，不再心算出错 |

## Agent 架构一览

```
用户消息 → 决策层（qwen3.8-flash，~1s：意图路由 + 技能匹配）
   ├─ 简单聊天 → 快速通道直答（2 次调用，秒回）
   └─ 复杂请求 → Agent Loop（qwen3.8-27b，≤6 步 + token 预算）
        ├─ 15 工具：解题/出题/笔记/单词/图谱/画板/诊断/沙盒…
        ├─ 10 技能：SKILL.md 渐进注入（Agent Skills 开放标准）
        ├─ 写工具：首次弹窗授权 + 每日限频 + 审计日志
        └─ 记忆五层 + P7 遥测（每步工具调用可回放）
贴图 → VL 两档路由（flash 提取 / plus 批改讲解）→ 配额 → 结构化结果
定时 → APScheduler：每日到期提醒 + 周五周报/计划进化
```

完整设计文档：[`AGENT_DESIGN.md`](AGENT_DESIGN.md)（决策记录 D1-D13 + 56 提交实施档案）。

## 双语桥接（核心差异化）

- **Harness 中文管道**：16 个数学主题中英双语词表，中文问题正确路由 + 证明判定
- **跨语言 RAG 检索**：中文问题可命中英文教材（"上确界"→"supremum"），反之亦然
- **双语出题**：英文题干（考试语言）+ 中文解析带术语对照；或全中文出题
- **双语基准**：24 题中英对称基准 **83.3%**（英文题 91.7%）
- **AI 人设**：中外合办桥接导师——中文回答 + 术语首现中英对照

## 用户系统

- **注册 / 登录 / 游客模式**（游客数据本地保存，登录后自动迁移上云）
- **多用户数据完全隔离**：文档、笔记、对话、记忆、图片——全部按用户隔离（e2e 跨用户 403/404 验证）
- **安全**：密码 PBKDF2 哈希、JWT + 改密吊销全部旧会话、OWASP 邮件重置链路、每 IP 限流
- **同源部署**：FastAPI 直接托管前端，敏感文件白名单隔离（.env/数据库不可达）

## 技术栈

| 层 | 技术 |
|----|------|
| 前端 | Vanilla JS 模块化（24 模块）+ PDF.js + Plotly + KaTeX + Lucide |
| 后端 | FastAPI + SQLite + JWT + APScheduler（定时任务） |
| 生成模型 | Qwen3.8-27B（阿里云百炼） |
| 决策层 | Qwen3.8-Flash（意图路由/技能匹配/等价判分，~1s/99tokens） |
| 视觉模型 | Qwen3-VL 双档（flash 提取 + plus 批改/讲解） |
| Harness 引擎 | V3（ToRA + Proof Verifier + Smart Routing + 中文管道） |
| 记忆引擎 | **FSRS-5**（官方公式实现，2 万+学习者预训练参数冷启动） |
| 计算沙盒 | 三层隔离（AST 白名单 + 子进程空环境 + 资源封顶） |
| 检索 | FTS5 + 向量混合（text-embedding-v4 跨语言） |

## 快速开始（clone 并运行）

```bash
git clone https://github.com/pangyueming/ShuYue.git
cd ShuYue/code_v2

# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置 API 密钥（唯一必需）
# 复制 .env.example 为 .env，填入 DASHSCOPE_API_KEY（阿里云百炼控制台获取）

# 3. 启动服务
python server.py
# 首次启动自动完成：数据库建表（含 agent/记忆/复习队列）+ JWT 密钥生成
# 服务运行在 http://localhost:8001

# 4. 打开前端
# 浏览器打开 http://localhost:8001 → 注册账号 → 开始使用
```

**仍然只需一个 API Key**——其余配置（决策层/视觉模型/复习配额/邮件）均有合理默认值，见 `.env.example` 注释。
