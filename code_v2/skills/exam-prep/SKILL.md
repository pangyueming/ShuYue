# 考前冲刺 (Exam Prep)

## 铁律
- **必须先调 get_knowledge_map 获取学生真实掌握度数据**，不凭空规划。
- 复习路径按"弱项优先、投入产出比"排序。
- 给出具体时间分配（精确到半天）。

## 数据依赖
- **必需**：学生已完成学前诊断（assessments 表有数据）
- 工具链：`get_knowledge_map → 分析弱项 → 生成冲刺计划`
- 缺数据时：引导"先做3分钟前测"并调 `start_assessment`

## 生成流程

### 第一步：获取掌握度
```
调 get_knowledge_map
→ 返回 {avg_score, weak_topics, strong_topics, bridge_dangers, recent_quizzes}
→ 无数据 → "先做个3分钟诊断，我才能给你定制冲刺计划"
```

### 第二步：优先级排序
```
排序规则（从高到低）：
1. bridge_dangers（断层预警）— 不补会导致后续课全听不懂
2. weak_topics 中 quiz 正确率 < 50% 的 — 提分最快的短板
3. weak_topics 中 quiz 正确率 50-70% 的 — 巩固即可
4. strong_topics — 不投入，保持手感即可
```

### 第三步：时间分配
```
根据剩余天数（问学生或默认7天）：
- 60% 时间 → 弱项突破
- 25% 时间 → 中等巩固
- 10% 时间 → 强项保持（做1套综合卷即可）
- 5% 时间 → 考前整理（错题本+公式速查）
```

## 输出格式

```markdown
# 🎯 考前冲刺计划（N天）

## 你的现状
- 掌握度：X% | 弱项：A、B、C | 断层预警：D

## 优先级路径
| 优先级 | 主题 | 建议投入 | 策略 |
|:---:|------|:---:|------|
| 🔴 P1 | 极限（ε-δ） | 2天 | 从定义出发重做3道证明 |
| 🟡 P2 | 级数收敛 | 1.5天 | 比较判别法+比率法专项 |
| 🟢 P3 | 导数应用 | 0.5天 | 已掌握，做1套综合卷 |

## 每日安排
Day 1-2: ε-δ 定义 + 3道证明练习
Day 3-4: 级数收敛 + 2道判断题
Day 5: 综合模拟
Day 6: 错题复盘 + 公式速查
Day 7: 休息 + 轻度复习

## 💡 策略提示
- 你的断层预警在「推理与证明」——这是大学数学的核心思维
- 每做完一个主题，调 generate_quiz 验证掌握
```

## 边界
- 学生没说还剩几天 → 问一句"还有几天考试？"
- 弱项超过 5 个 → 只列前 3 个（避免焦虑），其余提示"后续逐步补"
