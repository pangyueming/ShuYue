# 文档知识导航 (Document Guide)

## 铁律
- **永远先调 read_document 检查是否有知识指南**（study_guide），不要直接读原始文本。
- 有指南时用**结构化数据**回答（章节摘要/术语/模式），标注"来自《教材名》"。
- 无指南时 fallback 到原始文本（read_document 会自动处理）。
- **不要编造教材内容**——只使用工具返回的数据。

## 触发条件（两种）

### 自动：教材上传时后台自动生成（无需选技能）
```
学生上传教材 → 后台 30s 生成 → read_document 自动使用
```

### 手动：选中此技能 + @引用文档
```
学生选中"文档导航"技能 → @引用某文档 + 要求分析
  → 先调 generate_study_guide("文档名")（首次约30秒，需用户确认）
  → 生成完成 → 调 read_document 获取结构化导航
  → 按下述路径回答
```

**注意**：学生只是@引用但没选此技能 → 不触发蒸馏（正常上下文注入）。
学生选了此技能但没@ → 询问"要分析哪份文档？"

## 三种查询路径

### 1. 章节级查询（"第X章讲什么"/"这本书的结构"）
```
调 read_document("教材名")
→ 返回 chapters: [{id, title, summary}]
→ 列出章节索引让学生看到全貌
→ 学生选感兴趣章节 → 用章节 summary 回答
```

### 2. 术语查询（"X 是什么"/"X 的定义"）
```
调 read_document("教材名")
→ 返回 glossary: [{term_en, term_zh, chapter, def}]
→ 在术语表中查找匹配项 → 给出中英对照定义 + 所在章节
→ 没找到 → fallback 到 search_textbook（RAG精确搜索）
```

### 3. 解题方法查询（"怎么证明"/"有什么技巧"）
```
调 read_document("教材名")
→ 返回 patterns: [{name, desc}]
→ 列出相关模式 → 用模式内容回答
```

## 与 RAG 的协同

| 查询类型 | 用哪个工具 |
|---------|-----------|
| "第X章的核心概念" / "这本书讲什么" | read_document（guide） |
| "supremum 的定义是什么" | read_document（guide 的 glossary） |
| "证明极限的步骤" | read_document（guide 的 patterns） |
| "找到含 ε-δ 的原文段落" | search_textbook（RAG） |
| "教材里哪里讲了夹逼定理" | search_textbook（RAG） |

**原则**：概念理解用 guide，精确找原文用 RAG。

## 边界
- 学生上传新教材后指南未生成（约30秒后台处理）→ 告知"正在生成知识指南，稍后可查询"并先用原始文本回答。
- 课件/习题等非教材分类无指南 → 直接走原始文本路径。
