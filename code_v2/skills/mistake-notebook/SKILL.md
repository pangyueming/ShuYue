# 错题本生成 (Mistake Notebook)

## 铁律
- **必须先调 get_quiz_mistakes 获取真实错题**，不要凭空编造。
- 每道错题都要归因到六类错误模式之一。
- 最终调 create_note 保存错题本（tag 标注"错题本"）。

## 数据依赖
- **必需**：学生已做过至少一次 AI 出题（quiz_results 表有记录且有错题）
- 工具链：`get_quiz_mistakes → 分析归因 → create_note`
- 缺数据时：告知"先做一套练习题"并建议调 `generate_quiz`

## 生成流程

### 第一步：获取错题
```
调 get_quiz_mistakes(limit=10)
→ 返回 [{question, topic, date}, ...]
→ 无错题 → "最近测验全对！保持！🎉"
→ 无记录 → "先做一套练习，我帮你分析"
```

### 第二步：按主题分组 + 归因
每道错题按六类模式归因：
| 模式 | 特征 |
|------|------|
| 概念性 | 定义理解偏差 |
| 程序性 | 步骤/计算错误 |
| 符号性 | 记号转写错误 |
| 策略性 | 方法选择不当 |
| 语言性 | 英文题意误读 |
| 迁移性 | 高考习惯误用 |

### 第三步：生成错题本并保存
调 create_note：
- title: "错题本 · [日期] · N题"
- tag: "错题本"
- content: 按主题分组的结构化错题本

## 输出格式（笔记内容）

```markdown
# 错题本 · 2026-09-26 · 5题

## 极限（3题）
### ❌ 第1题：求 lim(x→0) sin(3x)/x
- **错误模式**：概念性 — 把 sin(3x) 等同于 sin(x)
- **正确思路**：利用 lim sin(u)/u = 1（当 u→0），令 u=3x
- **变式练习**：求 lim(x→0) sin(5x)/x

## 级数（2题）
...
```

## 边界
- 错题超过 15 道 → 只取最近 10 道，提示"其余错题可后续整理"。
- 与 error-analysis 技能互补：error-analysis 做单题深度诊断，mistake-notebook 做批量整理。
