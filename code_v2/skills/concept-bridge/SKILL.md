# 概念深度桥接 (Concept Bridge)

## 铁律
- 只深入讲**一个概念**——学生问多个时，先选最核心的讲透。
- 三层递进必须有：高考阶段 → 大学阶段 → 前沿/应用。
- 术语首现附英文对照。

## 数据依赖
- 无系统数据要求——纯教学方法论。
- 可选增强：调 search_textbook 查教材原文、调 get_knowledge_map 查掌握状态。

## 讲解结构（知识旅程四层）

### 第一层：高考阶段
- 高考怎么教这个概念（中文教材、计算导向）
- 典型题型和常用技巧
- 学生的直觉来自哪里

### 第二层：大学阶段（衔接断层）
- 英文教材怎么重新定义它（严格化/公理化）
- **断层点**：高考直觉哪里不够用
- 用一个对比例子展示思维升级

### 第三层：深层理解
- 这个概念背后的数学思想（为什么这样定义）
- 与其他概念的联系（前置→后续）
- 在整个数学大厦中的位置

### 第四层：前沿/应用
- 这个概念在后续课程中的发展（如实分析→测度论→泛函）
- 在工程/物理/AI中的应用
- 留一个开放问题引发思考

## 输出格式示例

```markdown
# 🌉 知识旅程：极限 (Limit)

## 高考阶段
极限 = "代入算值"...（直觉方法）

## 大学阶段
ε-δ 严格定义：∀ε>0, ∃δ>0...（形式化）
**断层**：高考可以画图得结论，大学必须证明存在这样的 δ

## 深层理解
为什么需要 ε-δ？→ 处理"无穷接近但不等于"的精确语言
前置：不等式 | 后续：连续、导数、积分、级数

## 前沿
ε-δ → 拓扑空间的邻域 → 度量空间 → 泛函分析
应用：数值分析中的误差估计、机器学习中的收敛性
```

- 与 gaokao-bridge 互补：bridge 讲"差异对比"，本 skill 讲"完整旅程"。
- 学生概念太宽泛（"讲讲微积分"）→ 缩小到核心概念（"从极限开始？"）。
