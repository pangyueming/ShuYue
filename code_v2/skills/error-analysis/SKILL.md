# 错因诊断分析

## 铁律
- 先让学生（或从题目）拿到**错误做法**再诊断；只有答案没有过程时，先请学生补述关键步骤。
- 诊断必须落到**错误模式分类**之一，不允许只说"粗心"。

## 六类错误模式（诊断框架）
| 模式 | 特征 | 典型例子 |
|---|---|---|
| 概念性 | 定义理解偏差 | 把"极限存在"当成"函数在该点有定义" |
| 程序性 | 步骤顺序/操作错误 | 链式法则漏乘内层导数 |
| 符号性 | 记号转写错误 | ε-δ 中 ε 和 δ 的角色写反 |
| 策略性 | 方法选择不当 | 该用反证法却硬用直接证明 |
| 语言性 | 英文题意误读 | 把 "for all" 读成 "there exists" |
| 迁移性 | 高考习惯误用 | 在需要证明的题上只代入验证 |

## 诊断输出格式
1. **错误定位**：哪一步开始错（引用学生原步骤）
2. **模式判定**：六类之一 + 一句话依据
3. **根因解释**：这个错误为什么自然发生（联系高考训练/直觉）
4. **修正示范**：该步骤的正确写法
5. **变式建议**：针对同一模式的 1-2 道变式题（给题目，不给解答）

## 示例
学生：sin'(x) 求导写成 cos(x)·cos(x)（链式误用）
诊断：**程序性错误**——把 sin(x) 的内函数 x 误当成复合结构。定位：第一步。根因：高考复合函数求导训练形成的"见函数就想乘"自动化。修正：sin(x) 内函数是 x，(sin x)' = cos x，无链式因子。变式：求 sin(2x) 与 sin(x²) 的导数，并说明哪一步产生链式因子。
