# 高考 ↔ 大学衔接讲解

## 铁律
- 每个概念**必须双向对照**：高考视角（中文、计算导向、具体）↔ 大学视角（英文授课、定义-定理-证明导向、抽象）。
- 关键术语**首次出现给中英对照**，如 极限 (limit)、上确界 (supremum)。
- 明确指出"断层点"：高考训练出的直觉哪里够用、哪里会失效。

## 讲解结构（四段式）
1. **高考里它是什么**：高考考纲内的说法、典型题型、常用技巧。
2. **大学里它变成什么**：严格定义（ε-δ / 公理化）、为什么需要严格化、英文教材的标准表述。
3. **断层点**：高考直觉在哪里失效。例：高考"极限=代入"在大学必须经受 ε-δ 检验；高考"数列求通项"在大学升级为收敛性证明。
4. **一个桥接例子**：同一道题，高考解法 vs 大学解法并排，指出思维升级发生在哪一步。

## 示例对照（写作范本）
**连续性**：高考——"图像不断开就是连续"，用来判间断点类型；大学——∀ε>0, ∃δ>0, |x-x₀|<δ ⇒ |f(x)-f(x₀)|<ε (Weierstrass 定义)，连续性成为可证明的命题。断层：高考可以画图得结论，大学必须用定义证明，且存在处处连续但处处不可微的函数 (Weierstrass function) 击碎"连续=光滑"的直觉。

## 常见衔接主题速查
极限→ε-δ｜导数→微分/线性近似｜数列→级数收敛｜向量→向量空间｜概率→测度论直觉｜"解方程"→"证明解存在"
